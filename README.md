# 弈间 · Chess & Cheers

暖纸色、胡桃木、朱红印记与中文衬线排版构成的棋类游戏空间。支持中国象棋、五子棋、国际象棋、黑白棋、井字棋，以及独立 3D 魔方与鲁班锁解谜。棋类含本地双人与休闲人机对弈。

## 使用

无须安装依赖，Python 3 即可启动：

```sh
cd app  # 如果你在 chess_is_cheers 工作区根目录
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173 。从本仓库根目录运行时直接执行第二行。

有 Node.js 22+ 时，也可用 `npm run dev` 启动；`npm test` 执行规则测试，`npm run build` 检查静态发布产物。

## 已实现

- 游戏大厅、棋类筛选、独立对局室。
- 五种棋类的完整单局流程、本地双人与休闲电脑对手；独立魔方遵循经典配色并支持 柔和六色、底面视角、18 步随机打乱、面转动画、撤销与复原判定；鲁班锁提供六销 3D 顺序拆解关卡。
- 2D / WebGL 真实 3D 视角切换，15–65° 倾角、360° 拖动环绕、滚轮缩放和一键转向。
- 棋盘大小默认 1.5×，可调至 1×–1.5×；放大时自动腾出版面，窄屏可横向浏览。大小与经典木纹、山川地形、世界地图主题偏好自动保存。
- 合法落点提示、最近一手标记、悔棋、重开确认。
- 当前浏览器自动存档、恢复进行中棋局、最近 30 局终局记录。
- 国际象棋 PGN 导出，其他棋类 JSON 棋谱导出。
- 一步将杀练习（首版固定第 001 题）、3D 三阶魔方 18 步打乱挑战、落子音效、桌面与手机布局。
- 吃子触发碎光、棋盘震动与不同音色；黑白棋逐子翻转，国际象棋有走子弧线与易位动画。
- 获胜庆祝、礼花、棋子欢呼与可点击奖杯中的隐藏猫猫彩蛋；平局与电脑胜利有各自文案。
- 「体验特效」可预览吃子与胜利画面，不修改棋谱；支持特效开关及系统减少动态效果。
- 国际象棋支持王车易位、吃过路兵、四种兵升变及规则库提供的和棋判定。

3D 模式使用本地打包的 Three.js 0.180.0：旋转曲面棋子、立体王冠、挤出马头、多层木质底座、金属饰边及实时光照阴影；主光跟随镜头方位，环绕视角时投影会相对棋盘转动。可点击棋子落子、拖动环绕和滚轮缩放。WebGL 不可用时自动回退 2D。渲染按需执行，切换页面或隐藏窗口时停止动画。地图是原创风格化装饰，不改变棋类规则，不是地图领土战略玩法；不用于地理精确测量。

电脑定位为休闲陪练：五子棋为攻防启发式，黑白棋考虑角位、行动力与翻子数，井字棋采用完整搜索，国际象棋采用两层搜索。未接入 Stockfish。

## 数据与边界

无需账户；存档位于浏览器 localStorage，同一设备的不同浏览器及线上/本地地址之间不会自动同步。隐私模式、存储权限限制或清除数据会影响留存，请导出重要棋谱。目前无远程联机、账号、积分、匹配、聊天或服务端数据库。

界面中文字体优先加载 Google Fonts 的 Noto Serif SC，失败时回退系统宋体；全部棋类逻辑、棋子、主题地图均为本地资源。

## 中国象棋

新增 9 路 × 10 线棋盘、楚河汉界与九宫；2D 木质圆子及 3D 带字立体木子使用同一规则局面。支持红方先行、人机/本地双人、选子与合法落点、将军提醒、吃子震动碎光、胜利彩蛋、悔棋、存档恢复和 JSON 棋谱导出。棋谱使用 A–I / 1–10 坐标，例如 `炮 B3→E3`，不是中文纵线数字的传统记谱。

基本走法包括车、马腿、象眼、九宫、炮架、过河兵及将帅照面；任何走法均不能使己方处于被将军状态。将死和困毙均判负。电脑采用两层搜索和子力/位置评价，定位休闲陪练。

重复及和棋为明确的休闲版约定：单方在重复循环内每手将军、另一方没有每手将军时，单方长将判负；其他同局面三次重复判和；连续 120 手（双方各 60 手）未吃子判和；双方均无车、马、炮、兵卒等进攻子力时判和。复杂长捉、比赛例外条款与裁判裁决未实现，不宣称完整遵循比赛裁决规则。

规则参考：[世界象棋联合会规则](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_XiangQi_Rules_English2018.pdf)。中国象棋新增 18 项规则/AI/存档测试，加上原有测试共 37 项。初始局面合法走法为 44，展开两手为 1920。
